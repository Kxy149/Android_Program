# 实验三：Fortune500 数据分析与可视化

## 实验目的

掌握使用 Python（pandas、matplotlib、seaborn）进行数据加载、探索、过滤、查询和可视化的基本方法。

## 数据集

Fortune 500 数据集（`fortune500.csv`），包含世界500强企业的排名、公司名称、收入、利润、年份等信息。

## 环境依赖

- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn

安装依赖：

```bash
pip install pandas numpy matplotlib seaborn
```

## 运行方式

```bash
python "%matplotlib inline.py"
```

或在 VSCode 中打开文件，点击右上角运行按钮（▶）。

## 实验内容

### 1. 数据显示
- 输出数据集形状（行数 × 列数）
- 展示前 5 行和后 3 行数据

### 2. 检查数据列属性
- 列名列表
- 各列数据类型
- 缺失值统计
- 基本统计信息（均值、标准差、分位数等）

### 3. 数据过滤
- 自动选取第一个数值列，按中位数过滤
- 输出过滤后的行数和数据预览

### 4. 属性查询
- 使用 `iloc` 切片查询指定行列
- 使用 `query()` 进行条件查询
- 使用 `value_counts()` 对分类列分组计数

### 5. 利润按年份分布
- **分面直方图**：按年份分列展示利润分布，带 KDE 密度曲线
- **箱线图**：按年份分组对比利润的中位数和四分位距

### 6. 利润与收入关联分析（一张图三子图）
| 子图 | 内容 |
|------|------|
| 散点图 | 收入 vs 利润，颜色映射年份 |
| 双轴趋势图 | 柱状图（总收入）+ 折线图（总利润），按年汇总 |
| 利润率直方图 | 利润/收入分布，红线标记中位数 |
